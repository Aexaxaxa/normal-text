# Нормальный Текст

Учебный frontend-проект сервиса типографической нормализации текста и документов.

## Назначение

Сервис позволяет пользователю:
- вводить текст вручную или загружать TXT/DOCX;
- выбирать русский или английский набор правил;
- настраивать режим и активные правила;
- запускать детерминированную типографическую обработку;
- просматривать изменения «было / стало»;
- принимать или отклонять изменения;
- копировать или экспортировать результат.

## Технологический стек

- React + TypeScript + Vite
- React Router
- Redux Toolkit
- Tailwind CSS
- localStorage
- mammoth / docx для DOCX
- Vitest + React Testing Library
- Git + GitHub

После установки зависимостей:

```bash
npm install
npm run dev
```
