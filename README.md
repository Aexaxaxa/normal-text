# Нормальный Текст

Учебный frontend-проект сервиса детерминированной типографической нормализации текста.

## Первая версия MVP

Основной сценарий:

1. Ввести текст вручную.
2. Выбрать язык правил и режим обработки.
3. Запустить типографическую проверку.
4. Просмотреть найденные изменения.
5. Принять или отклонить отдельные изменения.
6. Скопировать итоговый текст.

В первой версии реализованы 7 формализованных правил полного режима и 4 правила базового режима. ИИ не используется внутри продукта.

## Запуск

Требуется Node.js 20.19+.

```bash
npm install
npm run dev
```

Проверки:

```bash
npm test
npm run build
```

## Ограничения первой версии

- импорт TXT/DOCX пока не реализован;
- экспорт файлов пока не реализован;
- отдельная страница настройки правил пока не реализована;
- полный каталог правил из PRD будет расширяться последовательно.

## Технологии

- React + TypeScript + Vite
- CSS
- Node test runner для rule engine
- Git + GitHub
