# Нормальный Текст

Клиентский веб-сервис детерминированной типографической нормализации текста. Приложение не использует ИИ для обработки пользовательского текста: все изменения выполняются формализованными правилами.

## Возможности MVP

- ручной ввод текста и загрузка TXT/DOCX;
- русский и английский наборы правил;
- режимы «Базовый», «Полный» и «Пользовательский»;
- расширенный отдельный каталог правил для русского и английского режимов, объединённый по категориям;
- отдельная страница настройки категорий и отдельных правил;
- сохранение настроек обработки в localStorage без сохранения пользовательского текста;
- детерминированная обработка и перечень найденных изменений;
- принятие/отклонение отдельных изменений, «Принять все» и «Отклонить все»;
- фильтрация изменений по категориям;
- «Посмотреть в тексте» с подсветкой и прокруткой к изменению;
- сравнение исходного текста и результата;
- копирование результата;
- экспорт результата в TXT и DOCX;
- сохранение поддерживаемой структуры DOCX: абзацы, заголовки, списки, полужирное и курсивное начертание в пределах определённого формата;
- состояния загрузки, обработки, ошибок, отсутствия изменений и успешных операций;
- адаптивный интерфейс для desktop/mobile;
- прямые маршруты: `/`, `/rules`, `/review`.

## Запуск

Требуется Node.js 20.19+.

```bash
npm install
npm run dev
```

После запуска Vite покажет локальный адрес, обычно `http://localhost:5173/`.

## Автоматические тесты

Автоматические тесты покрывают три ключевые группы пользовательского поведения:

1. **Ввод и обработка текста** — пустой ввод блокируется, текст с нарушениями открывает Review, корректный текст показывает состояние «Изменений не найдено».
2. **Review и принятие решений** — отдельные изменения можно принять/отклонить, массовое принятие обновляет все карточки, режим сравнения подсвечивает выбранный фрагмент.
3. **Настройки правил** — родительский переключатель корректно отражает состояния ON/OFF/MIXED, категория управляет дочерними правилами, сохранение переводит изменённый набор в пользовательский режим.

Запустить все автоматические тесты:

```bash
npm test
```

Только unit-тесты rule engine:

```bash
npm run test:engine
```

Только React component/integration tests:

```bash
npm run test:ui
```

Интерактивный watch-режим:

```bash
npm run test:watch
```

Production build:

```bash
npm run build
```

GitHub Actions автоматически выполняет полный набор тестов и production build при каждом изменении `main` и в pull request.

## Технологии

- React + TypeScript + Vite
- React Router
- CSS
- mammoth — чтение DOCX
- docx — формирование DOCX
- DOMPurify — безопасная обработка HTML, полученного при разборе DOCX
- localStorage — только настройки правил
- Node test runner — unit-тесты типографического движка
- Vitest + React Testing Library + jsdom — component/integration tests

## Границы проекта

В MVP сознательно не входят орфографическая, грамматическая и стилистическая проверка, автоматическое определение языка, PDF, аккаунты, облачное хранение, backend и AI внутри сервиса.
