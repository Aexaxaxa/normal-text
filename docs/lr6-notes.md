# ЛР6 — первая версия MVP

## Основной сценарий

Ручной ввод текста → выбор языка/режима → проверка → просмотр изменений → принятие/отклонение → копирование результата.

## Реализовано

- React-редактор по макетам Figma;
- валидация пустого ввода;
- состояния обработки и отсутствия изменений;
- детерминированный rule engine: 4 правила в базовом режиме и 7 в полном;
- русский и английский режимы;
- экран Review с «Было / Стало»;
- принятие и отклонение отдельных изменений;
- подсветка выбранного изменения в обработанном тексте;
- «Применить все»;
- копирование результата;
- адаптивный desktop/mobile интерфейс;
- unit-тесты rule engine.

## Использование AI

AI использовался для анализа требований, декомпозиции задач, реализации компонентов, rule engine, тестов и проверки кода. Каждая часть выполнялась отдельным инкрементом.

Во время тестирования AI-реализации обнаружена ошибка правила единиц измерения: JavaScript `\b` не обеспечивал нужную границу для кириллических единиц (`кг`, `г` и т. п.). Правило было исправлено на явную проверку конца строки, пробела или знака препинания, после чего все unit-тесты прошли.

## Известные ограничения

- TXT/DOCX import отложен;
- файловый export отложен;
- отдельная страница настройки правил отложена;
- каталог типографических правил пока сокращён до набора, достаточного для демонстрации основной ценности MVP;
- backend, база данных и аутентификация не используются.
